# 이전 연구·설계·실행 기록

과거 보고서·JSON·실험 준비 문서·모델/Arena 조사 도구·이전 보고서 생성기·브라우저 QA 보조 도구를 원본 바이트 그대로 보존했습니다. `docs/`, `tools/`, `scripts/`, `tests/`는 원래 경로를 기록하기 위한 하위 구조이며 현재 제품에서 import하거나 실행하지 않습니다.

모델 단위 평가·100점 가중치·회사 성능 점수화·옛 survey-v1/실행 준비 명령은 현재 기능이나 현재 검증 결과가 아닙니다. 예전 코드에 있던 미완성 연결과 오래된 문서 링크도 역사 내용으로 보존했으며, 제품에 맞춰 복원하지 않았습니다.

원래 경로 → 보존 경로는 [전체 분류 목록](../../docs/production-cleanup-manifest.json), 이동 전후 해시는 [보존 목록](../production-cleanup-preservation.json)으로 확인할 수 있습니다. 원본 사용자 문서 두 개와 미커밋 Deliverable First 기록은 기존 `docs/` 위치에 남아 있습니다.

현재 구현과 명령은 [루트 README](../../README.md) 및 [현재 문서 안내](../../docs/README.md)를 기준으로 합니다.
