# 프롬프트 추천 웹페이지 전환

현재 제품 명세는 2026-10-28 마지막 사용자 지시다. 앞선 모델·서비스 추천 및 Super Agent 비교 방향은 폐기한다. 기존 Git 기록, 설정, 제공 DOCX, 제작 증빙을 보존하고 commit/push/배포하지 않는다.

## 상태 점검과 구현 계획

- 프로젝트의 AGENTS.md 검색 결과 없음. 사용자 자료 DOCX 두 개와 기존 미커밋 변경을 확인했다.
- 중단 시 발견: WorkflowStep의 새 필수 필드와 기존 엔진 불일치, StepKind와 템플릿 키 불일치, 누락된 buildStagePrompt/stagePromptContext import, 이미지 생성 인수 타입 불일치 등 타입 오류 7개. 기준 `npm.cmd test`는 76개 통과·미완성 workflow 테스트 1개 시작 실패였다.
- 이번 환경에서는 기존 의존성이 사용 가능해졌다. 이전 세션의 설치 실패를 현재 검증 결과로 재사용하지 않는다.
- 이전 앱 소스·데이터·테스트·README를 `archive/legacy-app/`에 옮겨 그대로 보존한다. 미완성 변경도 아카이브에 포함하며 현재 src와 테스트에서 분리한다. 연구 문서 및 과거 투표 데이터는 과거 자료임을 명시한다.
- 현재 앱은 React/Vite/TypeScript/Tailwind를 유지하고, 입력 → 선택적 조건 보완(최대 3개) → 편집·복사 흐름으로 단순하게 구성한다. 새 라이브러리는 추가하지 않는다.
- 조건 추출과 수동 수정, 간결한 템플릿·선택적 복합 작업, 초안 유지·재생성·복구, 실제 복사 결과와 수동 경로를 회귀 테스트로 검증한다. 타입·빌드 및 가능한 실제 브라우저 확인까지 진행한다.

## 현재 구현

서비스명은 **AI..may I..?**다. 밝은 배경, 짙은 네이비 본문, 절제된 보라색 주 행동을 사용한다. 홍보·추천 카드 대신 작업 입력과 큰 편집창을 중심에 둔다.

- 입력: 빈 입력 오류와 포커스, 입력만 채우는 대표 예시, 선택적인 조건 직접 수정. 파일 업로더는 없다.
- 조건 보완: 사용 목적·대상 독자·결과 형식·분량·말투·제약 중 중요한 누락만 최대 3개. 충분한 입력은 바로 결과로 이동한다. 건너뛰기는 미정으로 남고 같은 항목을 재질문하지 않는다.
- 결과: 목표·알려진 조건·필요한 입력 위치·제약·확인 기준으로 기본 프롬프트를 구성한다. 불필요한 문맥·자료·항목을 모든 요청에 붙이지 않는다. 사용자가 별도 수정한 조건은 원래 문장보다 우선한다.
- 복합 작업: 문서→발표와 같이 인계가 필요한 경우에만 선택적 단계별 초안을 제공한다. 최종 대본 형식을 분석·구성·이미지 단계에 일괄 상속하지 않는다. 실제로 읽지 않은 자료나 앞 단계 결과는 명시적 붙여넣기 위치로 남긴다.
- 후속 프롬프트·사용 팁·자기 점검은 접어두고 필요할 때 펼친다. 각 후속·단계별 초안도 편집·복사할 수 있다.
- 입력·명시적 조건 수정·기본/단계별/후속 편집·체크를 App 메모리에서 보존한다. 화면 이동/뒤로 가기에는 유지하고 새로고침하면 초기화한다. 새 작업 시작에는 직전 작업 복구를 제공한다.
- 조건을 변경해도 초안을 자동으로 덮어쓰지 않는다. 미반영 상태와 명시적 재생성, 한 단계 이전 초안 복구를 제공한다.
- 실제 클립보드 성공만 완료 알림으로 표시한다. 실패하면 편집창을 선택하고 수동 복사를 안내한다. 빈칸은 표시하고 사용자가 확인하거나 직접 채운 뒤 복사하도록 한다.
- 원문·조건을 URL, localStorage/sessionStorage, 분석 로그에 저장하지 않는다. hash에는 start/questions/result만 들어간다. history.state에는 화면 포커스/스크롤 정보만 보관한다.

외부 AI 호출·로그인·결제·업로드·자동 실행·외부 서비스 이동 버튼은 없다. 자료를 읽었다거나 특정 모델에 최적화됐다고 주장하지 않는다.

## 제거·분리한 기능과 보존

모델/서비스 추천 카드·선택·정렬, 서비스 카탈로그·상세·플랜 비교, 예산·가격·구독 입력, 벤치마크·Arena 평가, 모델-플랜 매핑, ChatKHU 실행 환경·모델 선택, Super Agent 비교 방향을 현재 UI와 실행 import에서 제거했다.

기존 코드를 숨기는 방식이 아니라 `src`에서 분리해 `archive/legacy-app/src/`로 옮겼다. 이전 테스트와 README도 같은 보관본에 포함한다. 중단된 코드의 미완성 상태는 보관본의 기록이며 현재 타입 검사·테스트 대상이 아니다. 보존본 자체의 실행 성공을 주장하지 않는다.

과거 `public/data/arena-public-votes.json`은 `archive/legacy-app/public/data/`로 옮겨 현재 배포 자산에서도 분리했다. 재계산·변조하지 않았다. 사용자 DOCX와 기존 조사·출처 문서는 원래 경로에 보존하고 `docs/README.md`에서 과거 자료로 구분했다. Super Agent 프로토콜은 최종 제품 범위에서 제외되어 새로 작성하지 않았다.

현재 코드가 사용하는 React, React DOM, lucide-react, Tailwind/Vite 의존성만 그대로 사용하며 라이브러리를 추가하지 않았다. `package.json`, lockfile, `vite.config.ts`, `.github/workflows/deploy.yml`은 변경하지 않았다. 기존 Pages base **`/AI...may-I../`**를 유지한다. `.git`, Git 기록, 비밀정보·로컬 설정, 사용자 제공 문서는 초기화·삭제하지 않았다.

## 남은 제한

- 규칙·템플릿 기반이므로 복잡한 문장·부정·중의적 요청을 항상 정확히 해석하지 못한다. 사용자가 조건과 프롬프트를 직접 고칠 수 있고, 모르는 값은 채우지 않는다. 특정 모델 최적화·성능 보장은 없다.
- 자료를 직접 읽지 않는다. 프롬프트의 자료·이전 단계 결과 위치는 사용자가 직접 채워야 한다. 실제 외부 답변 품질·이미지 생성·코드 실행 결과를 검증한 것이 아니다.
- 대괄호를 빈칸 후보로 보수적으로 표시하므로 정상 JSON 배열·인용 표시도 빈칸으로 안내될 수 있다. 사용자가 확인하면 그대로 복사할 수 있다.
- 현재 탭의 메모리만 보존한다. 새로고침 지속 저장·기기 간 동기화·다중 초안 이력은 범위 밖이다.
- 실제 브라우저 메뉴의 200% 확대는 조작하지 않았다. 동등한 작업 폭 리플로우를 확인한 결과다. 물리 휴대폰/다른 브라우저/스크린리더/모든 키보드 조합과 모든 색 상태는 미검증이다.
- GitHub Actions 실행·실제 Pages 배포, commit/push는 하지 않았다.
