# 웹 채팅 입력 및 실행 프롬프트 개선 계획

요청 명세: 이번 사용자의 두 변경 요청. commit·push·배포 금지. 카탈로그·평가·출처 보존.

기존 React/TypeScript 템플릿과 세션을 유지한다. 복사 본문은 작업 생성기가 담당하고 모델·계정 안내는 화면에서 담당한다. 기본 추천은 웹 채팅 후보만 연결하며, 정확 버전 미확인은 별도 표시한다. API·설치 평가 데이터는 참고 자료로 보존한다.

- [x] 회귀 테스트를 먼저 추가해 파일 설문 분석의 목적 축소, 메타데이터 유출, 과거 선택값 영향을 재현한다.
- [x] 우선순위·경로 입력 상태와 타입을 제거하고 오래된 세션을 정규화한다. 입력에서 후보 비교로 바로 이동한다.
- [x] 웹 채팅 후보와 평가용 참고 구성을 분리한다. API 기능을 웹 기능으로 상속하지 않는다. 추론 모드는 기존 근거를 유지한다.
- [x] 설문 단계 목적을 복구하고 요청별 본문을 생성한다. 최종 조건은 해당 산출물에만 적용한다. 모델 비교 요청의 명칭은 보존한다.
- [x] 초안 보존·복사 회귀·전체 테스트·타입 검사, 빌드 시도 및 브라우저 검사 갱신.
- [ ] 모바일·실제 클립보드 실행 확인: 브라우저 호스트 부재와 Chrome 제어 미승인으로 미실행. 프로덕션 빌드도 spawn EPERM으로 미완료.
- [x] 세 실제 요청의 생성 본문과 검토 결과를 보고한다. 외부 AI의 실제 응답 품질을 검증한 것으로 표현하지 않는다.

주의 입력: 파일 없는 설문, 분석만 요청한 설문, 사용자 수정 조건 충돌, 과거 API/CLI 세션, API 전용 모델. 검증 전 완료를 주장하지 않는다.
