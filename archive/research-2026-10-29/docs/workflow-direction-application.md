# 단계별 모델·프롬프트 중심 변경 기록

사용자의 후속 지시가 앞선 ChatKHU 설계 반영 명세와 충돌하는 경우 후속 지시를 우선한다. 기존 작업 트리의 구현과 사용자 문서는 보존하며 commit/push/배포하지 않는다.

## 구현 계획

1. 산출물·의존 관계 기반 규칙 분해, 출처 구분과 수정 가능한 단계 계약, 이미지 생성/기획 분리.
2. ChatKHU 실행 환경·모델/버전/모드·도구 근거 레지스트리, 빈 운영 모델 목록. 일반 서비스·플랜 후보와 분리.
3. 기존 단계 선택 화면을 기본 결과로 확장하고 단계 편집·모델 선택·개별 초안·인계·사용자 실행 표시 연결. 메모리 초안·복구·뒤로 가기 보존.
4. 수동 A/B 비교 프로토콜, 회귀 테스트, 기존 검사 실행과 환경 제한 기록.

코드 확인: 기존 recommend 엔진, WorkflowBuilder, PromptPanel, App 메모리 세션, 카탈로그를 확장한다. 기존 코드에는 ChatKHU 모델 목록·버전·모드·도구 지원 근거·확인된 접속 URL이 없다. 서비스 카탈로그로 이를 추정하지 않는다.

현재 환경 기준 실행: `npm.cmd test` 논리 테스트 66개 통과, 렌더 테스트 typescript 미설치로 시작 실패. `npm.cmd run typecheck`, `npm.cmd run build` 모두 tsc 부재로 시작 실패. 이전 설치 권한 오류가 해결된 근거가 없어 설치 반복/우회를 하지 않는다.

진행 중. 실제 구현 및 최종 검증은 완료 후 갱신한다.
