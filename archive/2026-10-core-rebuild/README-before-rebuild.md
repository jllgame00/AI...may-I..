# 최신 추천 정책 (2026-10-28)

결과 첫 화면에 작업별 우선 추천과 대안 2개를 표시합니다. 비교 가능한 원점수는 공동 순위를 포함해 계산하고, 설문·일반 한국어 글쓰기처럼 직접 근거가 부족하면 숫자 순위 없이 기능에 따른 우선 검토 후보를 제안합니다. 가격·무료 여부와 웹 채팅 권한은 성능 순위에 반영하지 않습니다.

기존 25개 모델·107건을 보존하고 동일 출처 비교 열 4건을 보완해 현재 **111건**입니다. [실제 코딩·설문·글쓰기 추천 결과와 검증 기록](docs/evidence-ranking-report.md)을 확인하세요. 아래 이전 변경 기록의 107건·이름순·일괄 순위 보류 설명은 당시 정책이며 이번 정책이 우선합니다.

# AI..may I..?

어떤 AI를 쓸지부터, 어떻게 쓸지까지.

사용자가 작업 목적·필수 기능·관련 평가에 맞는 AI를 비교하고 직접 선택한 뒤, 단계별 프롬프트와 검토·인계 안내로 활용하도록 돕는 서비스입니다. React + Vite + TypeScript + Tailwind CSS를 유지합니다.

## 현재 흐름

1. 작업을 입력하고 바로 AI 비교를 시작합니다. 첫 화면에는 작업 입력·클릭 가능한 예시·접을 수 있는 결과 세부 조건·실행 버튼만 있습니다.
2. 웹 채팅에서 쓸 후보를 작업 관련 평가·필수 기능 근거로 검토합니다. 우선순위와 API·CLI·설치 경로를 선택하지 않습니다. 품질 중심 정책은 고정이며 근거 없는 우열이나 일괄 max 설정을 만들지 않습니다.
3. 정확한 웹 모델 제공·필수 기능이 미확인인 후보는 별도 확인 필요 영역에 표시합니다. API·설치 전용 모델과 CLI·에이전트 실행 구성은 기본 선택에서 제외하고 전체 카탈로그·평가 참고로 보존합니다.
4. 후보 선택 후 모델 메뉴·플랜·권한·한도·Chat/Work 차이는 화면의 후보 상세와 이용 안내에서 확인합니다.
5. 작업 요청과 입력 위치·순서·산출물·확인 기준만 담은 프롬프트를 편집하고 복사합니다. 복사 버튼은 편집창의 본문 그대로 전달합니다. 결과를 검토한 뒤 필요한 앞 단계 결과만 다음 프롬프트에 붙여넣습니다.

복사·외부 이동·템플릿 준비만으로 작업 완료나 정확성 인증을 표시하지 않습니다. 편집 초안은 조건/AI가 바뀌어도 자동 덮어쓰지 않으며 명시적 재생성·이전 초안 복구를 제공합니다. 변경된 조건의 오래된 후보를 재사용하지 않도록 재비교를 요구합니다.

## 대표 시연

> 설문 통계값으로 결과를 분석하고 A4 4장 보고서를 써야 해.

작업 입력 → 웹 채팅 후보 비교 → 사용자 선택 → **통계 분석 → 결과 해석 → 보고서 초안 → 검토**.

통계 분석은 실제 계산·분석과 결과표 작성을 요청합니다. 자료가 없으면 먼저 요청하고 처리할 수 없으면 요약 통계·재현 코드 등 대안을 안내합니다. 권한 미확인이 단계의 목적을 바꾸지 않습니다. 수치·출처를 만들어 내지 않으며 최종 분량·말투는 보고서에 적용합니다.

## 근거와 범위

기존 ChatGPT·Claude·Gemini의 6개 구독 플랜과 API 과금 경로 2개를 유지하면서, **10개 제공사·정확한 모델 25개·실제 평가 관측값 107건**으로 확장했습니다. 기존 5개·13건 대비 **20개·94건 추가**이며 모드는 별도 모델로 세지 않습니다. 제공사 발표97건과 독립 Zapier 직접 평가10건, 모델 평가70건과 에이전트 실행 구성37건을 구분합니다. [정확한 ID·버전·출처·107건 전체 목록](docs/model-catalog-snapshot.md)을 확인할 수 있습니다. 새 소비자 플랜 연결을 추정하지 않았으며 가중치 체크포인트·공식 API·경로 미확인을 구분합니다.

일반 Chat·Work·API와 자체 호스팅 경로를 구분하고 정확한 모델·버전·설정과 실제 이용 연결을 별도 확인합니다. 소비자 연결 미확인으로 모델 평가를 숨기지 않습니다. Zapier AutomationBench1.0.6의10개 구성과 Grok 공식 발표의3개 코딩 평가별 구성 비교를 원점수로 제공하며, 도구·effort 차이를 밝히고 서로 다른 평가를 합산하지 않습니다. Qwen/Kimi의 글쓰기 참고 결과는 한국어 품질이나 현재 작업의 성공률로 일반화하지 않습니다. Artificial Analysis 공식 API/방법론/약관은 확인했지만 키·공개 활용 권한과 수치 접근 공백 때문에 실제 지수 수치는 수록하지 않았습니다. 관련 평가 원점수·조건을 표시하며 종합 100점으로 평균 내지 않습니다. 글쓰기·설문 통계에는 코딩 점수를 직접 연결하지 않습니다. 성능 자료 부족만으로 기능 기반 후보를 보류하지 않습니다. 모델의 성능 자료가 있어도 구독 제공 권한이 미확인이면 별도로 표시합니다. 가격 미확인은 모델 추천을 보류하는 이유가 아닙니다. 과거 2025년 Arena 공개 투표는 별도 참고 영역에 보존하며 현재 후보 선정·순서·동점 처리에 사용하지 않습니다.

ChatKHU 이용을 전제로 하지 않습니다. 이전 제작 과정의 활용 기록은 보존하며 현재는 공식 소비자 서비스·개발자 API·공개 가중치 경로와 실행 경로 미확인을 구분해 안내합니다. API는 사용자가 별도 환경에서 직접 실행하며 월 구독료와 별개입니다.

외부 AI 호출·ChatKHU API·로그인·결제·원본 파일 분석·자동 전송/실행·Super Agent 비교 실험은 없습니다. 통계 오류 감소·작업 성공률 등의 효과를 측정하거나 보장하지 않습니다.

## 이용 경로·AA 연결 보완

25개 모델·107건 평가와 기존 API·설치 경로 자료는 유지합니다. 기본 추천·선택은 웹 채팅 후보로 제한합니다. 기존 경로 조사는 공식 웹 서비스 존재와 정확한 평가 버전 제공을 구분하는 데 재사용하며, API 지원을 웹 제공 근거로 바꾸지 않습니다. CLI·에이전트 평가 비교는 접힌 읽기 전용 참고 영역으로 옮겼습니다.

[경로 조사 전체](docs/model-access-review.md)와 [AA 인증·공개 조건·실제 접근 범위·로컬 갱신 절차](docs/aa-data-integration.md)를 확인하세요. **이번에 앱에 추가한 AA 관측은0건**입니다. 인증 키 없음, 공개 구조화 점수/모델 선택 안내의 적용 조건, Coding Agent Index API 제공 미확인을 각각 기록했습니다. 접근 가능한 비교 원문에서는 실제 값을 확인했으나 구조 구현을 수치 연결 완료로 보고하지 않습니다.

AA 수집기는 `node scripts/aa-data.mts check|collect|prepare|publish`입니다. 키는 로컬 환경변수로만 읽고 원본은 무시되는 `.aa-cache/`에 저장하며 공개 갱신 전에 ID·버전·모드·지표·권한 범위를 검증합니다. 무료·예산 필터·가격 가중치는 없습니다.

## 상태와 실행

입력·조건·선택·단계별 편집·직접 검토 표시는 현재 탭의 메모리에 보존합니다. 화면 이동과 뒤로 가기에는 유지하며 새로고침하면 초기화합니다. 원문을 URL·브라우저 영구 저장소·분석 로그에 기록하지 않습니다.

Node.js 22.18 이상(워크플로는 Node.js 24)을 사용합니다.

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run typecheck
npm.cmd run build
npm.cmd run dev
```

`/AI...may-I../`를 엽니다. GitHub 저장소명·Pages base `/AI...may-I../`와 `.github/workflows/deploy.yml`은 그대로입니다. hash 화면 이동이라 별도 서버 라우팅이 필요하지 않습니다.

[이번 입력·복사 본문 변경과 실제 생성 예시·검증 한계](docs/web-chat-prompt-usability.md)를 확인하세요. 테스트·타입 검사 결과와 빌드·브라우저 실행 제한을 구분해 기록했습니다. 재현용 `tests/browser-check.mjs`는 preview 4173과 별도 Chromium 디버깅 세션 9222가 필요하며 단일 입력부터 웹 후보 선택·단계 목적·편집·실제 복사·초안 복구·320px 화면을 검사합니다. 이번 환경에서는 이 브라우저 시나리오를 실행하지 못했습니다.
