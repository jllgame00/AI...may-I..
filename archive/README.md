# 과거 구현 보관

`legacy-app/`은 2026-10-28 프롬프트 추천 도구로 전환하기 **직전 작업 트리의 보존본**이다. 기존 서비스 추천 MVP, 카탈로그·플랜·평가, 중단된 단계별 모델 추천 변경과 당시 테스트를 함께 보관한다.

- 현재 앱에서 import하거나 테스트·빌드하지 않는다. 현재 제품에는 모델/서비스/플랜 추천·순위·실험 기능이 없다.
- `legacy-app/src/`에는 중단 때문에 연결되지 않은 타입·함수·import가 있다. 보존본의 타입 검사/실행이 통과한다고 주장하지 않는다.
- `legacy-app/README.md`는 이전 시점의 기능과 검증 기록이다. 현재 제품 설명 또는 이번 실행 결과가 아니다.
- `legacy-app/public/data/arena-public-votes.json`은 과거 평가 자료다. 재계산하거나 덮어쓰지 않았고 현재 공개 앱 자산에서 분리했다.
- `legacy-app/tests/`와 소스 내부 테스트는 당시 범위의 기록이다. 재사용한 조건 수정 우선·초안 보존·복구·복사 실패 검증은 현재 테스트로 옮겼다.
- 원래 Git 이력과 `.git`, 로컬 설정·비밀정보는 보관 작업의 대상이 아니며 건드리지 않았다.

현재 소스는 프로젝트 루트 `src/`, 현재 설명은 루트 README 및 `docs/prompt-workspace-application.md`를 참조한다.
