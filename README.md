# AI..may I..?

어떤 AI를 쓸지부터, 어떻게 쓸지까지.

사용자가 작업·예산·필수 기능에 맞는 AI를 비교하고 직접 선택한 뒤, 단계별 프롬프트와 검토·인계 안내로 활용하도록 돕는 서비스입니다. React + Vite + TypeScript + Tailwind CSS를 유지합니다.

## 현재 흐름

1. 작업을 입력하고 예산(무료만/무료 선호/유료 허용/미정)과 우선순위를 고릅니다. 예시는 입력만 채웁니다.
2. 규칙으로 제안한 작업·필수 기능을 직접 확인·수정합니다. 자료가 요약 통계·텍스트인지 파일인지 구분하며, 모든 작업에 첨부·코드 실행을 강제하지 않습니다.
3. 확인된 조건에 맞는 후보를 이유·무료 범위·제한·공식 출처와 비교하고 선택합니다. 필수 정보 미확인과 확인된 불일치는 별도로 표시합니다.
4. 기본 선택은 전체 준비 단계에 적용합니다. 필요할 때만 특정 단계의 AI를 바꿀 수 있고 다른 단계 선택은 유지합니다.
5. 프롬프트를 직접 편집·복사하고, 별도의 공식 서비스 링크에서 사용합니다. 결과를 직접 대조·검토하고 확인한 내용만 다음 단계 빈칸에 전달합니다.

복사·외부 이동·템플릿 준비만으로 작업 완료나 정확성 인증을 표시하지 않습니다. 편집 초안은 조건/AI가 바뀌어도 자동 덮어쓰지 않으며 명시적 재생성·이전 초안 복구를 제공합니다. 변경된 조건의 오래된 후보를 재사용하지 않도록 재비교를 요구합니다.

## 대표 시연

> 설문 통계값으로 결과를 분석하고 A4 4장 보고서를 써야 해. 과제라 비용은 쓰고 싶지 않아.

무료만 / 결과 품질 우선 → 요약 통계 직접 입력인지 파일인지 확인 → 공식 근거가 있는 무료 조건 비교 → 사용자 선택 → **통계 분석 → 결과 해석 → 보고서 초안 → 검토**.

통계값·표본 수·분석 결과·출처를 임의로 채우지 않습니다. 파일 모드에서 확인된 무료 첨부 조건을 충족하는 후보가 없으면 그 사실과 확인 필요 후보를 안내합니다. 시연용 수치·품질 순위·가격을 만들지 않습니다.

## 근거와 범위

기존 ChatGPT·Claude·Gemini의 6개 구독 플랜을 유지하고, 정확한 모델 5개(GPT-6.1 Sol·Terra, GPT-6 Astra, Claude Sonnet·Opus 5.5)와 API 사용량 과금 경로 2개를 구분합니다. 2026-10-28 공식 원문에서 확인한 실제 평가 결과 13건(제공사 발표 10건·독립 Zapier 평가 3건)을 수록했습니다. 모든 구독 플랜의 현재 모델·권한·한국 결제 총액을 새로 확인한 것은 아니며, 출처별 확인일과 미확인을 보존합니다.

일반 Chat·Work·API 경로를 필터링하고 정확한 모델·버전·설정과 실제 이용 연결을 확인합니다. 관련 평가 원점수·조건을 표시하며 종합 100점으로 평균 내지 않습니다. 글쓰기·설문 통계에는 코딩 점수를 직접 연결하지 않습니다. 성능 자료 부족만으로 조건 기반 후보를 보류하지 않습니다. 과거 2025년 Arena 공개 투표는 별도 참고 영역에 보존하며 현재 후보 선정·순서·동점 처리에 사용하지 않습니다.

ChatKHU 이용을 전제로 하지 않습니다. 이전 제작 과정의 활용 기록은 보존하며 현재는 확인된 공식 소비자 서비스·개발자 API 경로를 안내합니다. API는 사용자가 별도 환경에서 직접 실행하며 월 구독료와 별개입니다.

외부 AI 호출·ChatKHU API·로그인·결제·원본 파일 분석·자동 전송/실행·Super Agent 비교 실험은 없습니다. 통계 오류 감소·작업 성공률 등의 효과를 측정하거나 보장하지 않습니다.

## 상태와 실행

입력·조건·선택·단계별 편집·직접 검토 표시는 현재 탭의 메모리에 보존합니다. 화면 이동과 뒤로 가기에는 유지하며 새로고침하면 초기화합니다. 원문을 URL·브라우저 영구 저장소·분석 로그에 기록하지 않습니다.

Node.js 22.18 이상(워크플로는 Node.js 24)을 사용합니다.

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run typecheck
npm.cmd run build
npm.cmd run dev
```

`/AI...may-I../`를 엽니다. GitHub 저장소명·Pages base `/AI...may-I../`와 `.github/workflows/deploy.yml`은 그대로입니다. hash 화면 이동이라 별도 서버 라우팅이 필요하지 않습니다.

[현재 모델 추천 기준·실제 확보 자료·검증 제한](docs/model-recommendation-methodology.md)과 [기존 흐름 적용 기록](docs/final-ai-guide-application.md)을 구분합니다. 후속 점검에서 테스트 99개·타입 검사가 통과했습니다. 앞서 빌드는 환경의 `spawn EPERM`으로 미완료였으며 후속 점검에서는 같은 실패 방식을 반복하지 않았습니다. 브라우저 검사 스크립트 구문 검사는 통과했지만 실제 브라우저 시나리오는 미실행입니다. `tests/browser-check.mjs`는 현재 빌드의 preview 4173과 별도 headless Edge 9222 세션이 필요하며, 기존 대표 흐름과 새 모델 선택·초안 보존을 검사합니다.
