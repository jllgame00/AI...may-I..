# AI 비교·선택·단계별 활용 최종 반영

2026-10-28 마지막 사용자 지시를 최종 제품 명세로 적용한다. 프롬프트 전용 전환과 추천 기능 삭제 지시는 취소됐고, Super Agent 비교 실험은 여전히 제외한다. 기존 미커밋 사용자 변경·문서·Git/배포 설정을 보존하고 commit/push/배포하지 않는다.

## 점검·진행 계획

- AGENTS.md 검색 결과 없음. 현재는 프롬프트 전용 앱이며 비교 엔진·공식 근거·과거 평가가 `archive/legacy-app/`에 보존돼 있었다. 중단 이전의 미완성 모델 환경 타입은 실행 코드로 되돌리지 않는다.
- 현재 밝은 네이비·보라 UI, 조건 추출, 초안 편집·보존·복구, 실제 클립보드·오류 처리와 화면 복귀를 재사용한다.
- 기존 공식 서비스 3개/플랜 6개·필수 기능/예산 필터·평가 요건 로직과 의미 있는 회귀 테스트를 복원한다. 추천 데이터는 새로 만들어 채우지 않는다.
- 입력과 예산/우선순위 → 규칙 해석 확인·수정 → 비교·사용자 선택 → 단계별 편집/복사·별도 공식 이동·검토/인계로 연결한다.
- 대표 설문 보고서는 요약 통계 직접 입력/파일/미정 구분을 확인하고, 통계 분석 → 결과 해석 → 보고서 초안 → 검토로 구성한다. 제공되지 않은 값/표본수/분석 결과는 명시적 빈칸으로 둔다.
- 테스트·타입·빌드·실제 브라우저 대표 흐름/모바일/복사 실패/뒤로/초안 보존을 검증하고 결과를 아래 기록한다.

## 구현 결과

기본 흐름은 **작업·예산·우선순위 → 규칙 해석 확인/수정 → AI 조건 비교·직접 선택 → 단계별 편집·복사 → 별도 공식 경로·직접 검토·인계**다. 서비스명은 `AI..may I..?`로 표시한다. 기존 밝은 배경·네이비 본문·보라 주 행동을 재사용하고 장황한 소개 없이 입력을 시작할 수 있게 했다.

### 복구·재사용

- `archive/legacy-app/`에서 기존 필수 기능·예산 필터, 미확인/미지원 구분, 유효 평가 요건 검사, 서비스 3개/플랜 6개의 공식 정보와 출처·접근 상태를 선별 복구했다.
- 현재 UI는 조건 비교와 중립적 이름순을 사용한다. 품질 우선으로 수치·품질 순위를 만들지 않는다. 현재 운영 모델·평가 연결은 미확인이고 점수는 null로 남긴다. 기존 계산 기능의 의미 있는 회귀는 보존했다.
- 모델·서비스·플랜·웹 경로를 구분하고 정확한 모델/버전/모드가 없으면 미확인으로 표시한다. 이 평가 연결 공백이 관련 없는 필수 기능 비교까지 막지는 않는다.
- 과거 Arena 참고 UI·파서·정적 스냅샷은 분리된 접기 영역에 복구했다. 현재 비교 엔진은 이 스냅샷을 읽거나 정렬/동점 처리에 적용하지 않는다. 스냅샷은 Git HEAD와 동일하며 재계산·덮어쓰기하지 않았다.
- 초안 편집·복사·실패 수동 선택, 명시적 재생성/복구, hash 이동·뒤로 상태·포커스, 새 작업/직전 작업 복구는 최근 구현을 재사용했다.
- 중단된 `StepKind`/모델 실행 환경 타입을 무작정 복구하지 않고, 검증된 엔진 타입을 `recommendationTypes.ts`로 분리해 현재 세션 타입과 연결했다.

### 대표 설문 시연

대표 예시는 사용자가 제공한 문장을 그대로 채우며 자동 제출하지 않는다. 무료만/결과 품질 우선 상태를 함께 설정한다.

요청 확인 화면에서 자료 분석·글쓰기와 A4 4장 목표를 확인한다. **요약 통계값/텍스트 직접 입력**, **파일 첨부 필요**, **미정** 중 자료 형태를 직접 정한다. 요약 통계를 직접 넣는 경우 파일 첨부나 코드 실행을 필수로 가정하지 않는다. 파일이 필요하면 일반 업로드와 형식별 기능을 조건에 포함한다.

직접 입력 조건에서는 현재 근거로 무료 3개 후보를 같은 조건 비교 수준에서 제시한다. 가격·성능·실제 통계 처리 성공을 만들어 넣은 결과가 아니다. 파일 모드는 무료 플랜의 업로드가 제한적/미확인이라 확인된 충족 후보 없음과 별도 확인 필요 그룹을 표시한다. 예산·필수 기능을 자동 완화하지 않는다.

선택한 기본 AI는 다음 네 단계에 공통 적용된다.

| 단계 | 목적·입력 | 산출물·직접 검토·인계 |
|---|---|---|
| 통계 분석 | 변수·단위·문항과 사용자가 준비한 통계값, 또는 확인된 경로의 파일/분석 범위 | 제공된 값 정리·가능/불가능 분석·미확인. 수치·분모·표본/결측 확인 후 검토한 통계표와 계산 방법 전달 |
| 결과 해석 | 앞 단계에서 확인한 통계표·변수·방법·한계 | 관찰 사실과 해석·추론 한계 구분. 인과/유의성 단정 여부를 확인하고 근거 수치·해석 한계 전달 |
| 보고서 초안 | 직접 확인한 통계·해석·출처·과제 기준 | A4 4장 또는 직접 수정한 분량/형식의 초안. 서식에 따른 페이지 수 차이는 확인하도록 안내. 표·본문 수치·인용을 대조하고 검토할 초안 전달 |
| 검토 | 초안·원자료·출처·과제 기준 | 위치·문제·근거·수정 제안 표. 사용자 직접 원자료 대조와 최종 확인 항목 |

제공되지 않은 통계값·표본 수·유의확률·분석 결과·출처는 채우지 않고 명시적 입력 위치로 남긴다. 이 사이트가 원자료나 앞 단계 결과를 읽고 있다는 표현을 쓰지 않는다.

모든 단계에서 모델 변경을 요구하지 않는다. 선택 사항으로 특정 단계만 다른 AI·플랜을 고를 수 있고 다른 단계 선택은 보존한다. 관련 후속 단계는 재확인 표시를 하며 기존 편집을 덮어쓰지 않는다. 선택·조건이 실제로 달라진 초안만 새 문맥 미반영 경고를 제공한다.

복사와 공식 서비스 열기는 서로 다른 동작이다. 복사·외부 이동으로 검토 표시를 하지 않는다. 사용자가 직접 대조·검토했다는 표시 후 다음 단계 버튼으로 진행할 수 있다. 단계 목록에서는 준비 내용을 미리 볼 수 있으며 이를 실제 실행 진행률로 표시하지 않는다.

### 실행 경로

공식 소비자 웹 경로를 기본으로 제공한다. ChatKHU에 해당 후보가 실제 제공되는 모델/버전/모드·플랜 연결은 현재 확인되지 않아 운영 ChatKHU 경로를 만들지 않았다. 테스트 전용 합성 연결에서만 정확한 플랜·모델·버전·모드·출처가 모두 일치할 때 별도 경로를 허용하는 계약을 검증했다. 일반 서비스 가입/카탈로그 항목을 ChatKHU 제공 근거로 쓰지 않는다.

## 발견·수정한 오류

| 문제 | 수정·증빙 |
|---|---|

| 글쓰기 요청의 명시적 PDF/파일 첨부가 분석 작업이 아니라는 이유로 사라짐 | 작업 종류와 독립적으로 파일 필요를 판단. 파일 모드에서 upload를 필수로 유지. 직접 텍스트 경로는 명시적 선택으로 구분 |
| 설문 파일 모드도 요약 통계 직접 붙여넣기만 요구 | 첫 단계 목적·입력·지시를 파일/직접 입력에 따라 분기하고 플랜 권한 확인·자료 미제공 시 질문을 명시 |
| 설문 템플릿이 직접 수정한 형식·미정 분량을 버림 | 명시적 수정/빈 값이 원래 문장보다 우선한다는 지시와 최종 형식 반영. 중간 산출물 형식은 별도로 유지 |
| 특정 단계 AI 변경이 다른 단계의 검토·초안 문맥까지 불필요하게 바뀔 수 있음 | 단계별 문맥을 분리하고 현재/후속 검토만 갱신. 다른 단계 선택·직전 검토·편집 보존을 브라우저 확인 |
| 자료 형태를 수정하면 입력 필드가 바로 사라져 키보드 흐름이 끊김 | 명시적으로 선택한 자료 형태는 계속 수정 가능한 필드로 표시. Tab/방향키/Enter 회귀 통과 |
| 이전 브라우저 검사가 취소된 전용 UI를 가정 | 당시 검사는 archive/prompt-only/tests/에 보존하고 현재 대표 흐름으로 tests/browser-check.mjs 갱신 |

기존의 결과 hash 새로고침 안전 복귀, 수동 조건 우선, 빈칸 확인·복사 성공/거부, 초안 보존·재생성·복구 회귀도 유지한다.

2. 네 단계, ChatGPT Free 선택과 공식 경로·프롬프트 일치, 빈칸 확인, 실제 클립보드 쓰기/읽기 성공. 복사해도 검토 체크 안 됨.
3. 실제 clipboard-write 권한 거부·수동 선택 안내. 특정 단계 Claude 선택 후 앞/뒤 단계 ChatGPT 유지, 앞 단계 편집/검토 보존, 후속 재확인 표시.
4. 뒤로 이동 시 초안 보존. 예산 변경 후 예전 비교를 보여주지 않고 재확인, 재비교 후 기존 편집 유지·미반영 경고·재생성/복구.
5. 320px 단계 화면·비교 화면 가로 넘침 없음. 1440px의 200%에 해당하는 720px 작업 폭 리플로우도 확인.
6. 파일 모드 무료 조건 충족 후보 없음과 확인 필요 그룹. 무료 조건 자동 완화 없음.
7. Tab/방향키/Enter로 입력→해석→자료 형태 수정→비교→선택→단계 준비. 페이지 예외 없음, 브라우저 저장소 원문 없음.
8. 결과 hash 새로고침은 안전하게 입력으로 복귀하고 다시 타이핑해도 사용 가능. URL에는 작업 원문 없음.

로컬 증빙: `.qa/ai-guide-browser-results.json`, `ai-guide-desktop.png`, `ai-guide-mobile.png`, `ai-guide-zoom-equivalent.png`. 스크린샷을 직접 열어 PC·모바일 배치를 확인했다. `.qa/`는 기존 ignore 대상이다.

## 데이터 제한·미검증

- 현재 상세 비교 근거는 3개 서비스·6개 기존 플랜이다. 이전 확대 조사 원본은 미확보였으며 나머지 서비스의 플랜·가격·기능을 새로 만들지 않았다. 전체 시장 조사 완료를 주장하지 않는다.
- 정보는 기존 2026-10-21 기록과 제공 문서에 명시된 2026-10-28 필드별 기록이다. 현재 작업에서 실시간 최신 재조사·실결제·한국 계정 실사용·도구 실제 처리 품질을 확인한 것이 아니다. 상충·미열람·지역/세금·사용량 미확인을 보존했다.
- 정확한 현재 평가 모델/버전/모드와 무료·유료 플랜 연결은 미확인이다. 실제 ChatKHU 모델 목록·모드·도구·경로를 제공받지 않아 운영 ChatKHU 경로를 안내하지 않는다.
- 규칙 해석은 복잡한 부정·선택 표현·복합 요청을 놓칠 수 있다. 사용자 직접 수정과 미정 보존을 제공한다. 실제 설문 통계 분석·원자료 읽기·외부 결과 품질 비교·통계 오류 감소 측정은 하지 않았다.
- 스크린리더, 물리 휴대폰, 다른 브라우저, 브라우저 메뉴의 실제 200% 확대 조작은 미검증이다. 확대는 동등 작업 폭 확인으로 구분한다.
- 외부 서비스 링크는 주소·선택 일치를 검사했으며 로그인·업로드·자동 전송/실행을 하지 않았다. 자기 검토 표시는 정확성 인증이 아니다.
- 상태는 현재 탭 메모리다. 새로고침 지속 저장·계정 동기화·다중 초안 이력은 범위 밖이다.
- commit/push/배포/GitHub Actions 실행은 하지 않았다. Super Agent 비교 실험도 수행하지 않았다.
