# AI..may I..? 모델 추천 기준과 실제 확보 자료

확인일: **2026-10-28**. 이 문서는 이번 모델 확장의 현재 기준이다. `final-ai-guide-application.md`의 기존 비교·선택·단계별 활용, 초안 보존 계약을 이어간다. 그 문서의 이전 검증 결과를 이번 결과로 재사용하지 않는다.

## 구현 범위

작업 입력 → 예산·필수 기능·이용 경로 확인 → 서비스·정확한 모델·플랜 비교 → 사용자 선택 → 단계별 프롬프트 편집·복사 → 외부 직접 실행·검토를 유지한다. 브랜드는 AI..may I..?이다.

- 기존 ChatGPT·Claude·Gemini **6개 구독 플랜 ID**와 개별 출처·확인일을 재사용했다. 가격·파일 권한 전체를 이번에 재확인했다고 주장하지 않는다. Claude 가격표는 이번에 다시 열람했다.
- 별도의 **OpenAI API / Anthropic API 사용량 과금 경로 2개**를 추가했다. 소비자 구독 상품 2개를 추가한 것이 아니다. API 가격은 USD/100만 토큰이며 구독료·무료 구독 혜택으로 변환하지 않는다. 캐시 입력·입력·출력을 나누고 도구·세금·총액은 별도 확인한다.
- 모델 5개, 실제 평가 결과 **13건: 제공사 발표 10건 / 독립 운영기관 직접 발표 3건**이다. 같은 모델의 다른 설정은 각각 별도 결과로 센다. 13개 평가 종류를 확보했다는 뜻은 아니다.
- 모델 정보·실행 연결·평가 결과는 각각 `currentModels`, `currentMappings`, `currentEvaluations`에서 관리한다. 기존 `observations`/`cohorts`는 과거 합성 테스트 계약용이며 새 자료를 그 가중 평균에 넣지 않는다.
- 기본 경로는 소비자 웹서비스(Chat / Work). 일반 웹 채팅, ChatGPT Work 웹, 개발자 API로 필터링할 수 있다. API 경로에서도 실행은 사용자가 직접 구성한다. 키 입력·호출·결제·자동 실행을 추가하지 않았다.
- ChatKHU는 필수 기능·일반 사용 안내에서 제외했다. 이전 제작 과정 문서와 정확한 대체 경로 연결을 검증하는 기존 합성 테스트는 보존했다.
- 초안 편집·복구·복사 실패 처리·검토 체크·hash 이동을 유지한다. 이름의 대괄호가 빈칸으로 오인되지 않게 모델 ID는 일반 텍스트로 표시한다. 같은 플랜의 여러 모델 선택 버튼은 고유 ID를 갖는다.

릴리스 이름과 API ID를 확인했으며 제공사가 공개하지 않은 날짜별 내부 체크포인트 ID를 만들지 않는다. 계열 이름만으로 별도 모델을 등록하지 않았다. 지원되는 다른 effort는 모델 카탈로그에 표시한다. 초기 준비 설정 medium을 최고 성능으로 검증한 것은 아니다.

모델명·ID·추론 설정·API 기능은 [OpenAI 모델 목록](https://developers.openai.com/api/docs/models), Work의 선택 방법·계정별 차이는 [ChatGPT Learn Models](https://learn.chatgpt.com/docs/models)에서 확인했다. Sol의 일반 Chat 미제공은 [Sol 공식 발표](https://openai.com/index/introducing-gpt-6-1-sol/)에 명시되어 있다. Claude의 모델·effort·thinking 설정은 [공식 도움말](https://support.claude.com/en/articles/8664678-change-the-model-effort-and-thinking-settings)에서 확인했지만 이것을 플랜별 권한표로 취급하지 않는다.

Work의 링크는 ChatGPT 진입점이다. 사용자가 Work와 Advanced 모델·설정을 직접 선택한다. 링크만 열어 모델·모드가 선택되었다고 표시하지 않는다. 계정·출시 단계별 옵션 차이를 카드와 프롬프트에 안내한다. 일반 Chat 플랜의 업로드·검색·분석 권한을 Work에 복사하지 않는다. 확인한 OpenAI API의 네이티브 이미지 입력은 지원으로 인정하되 파일 업로드·이미지 생성·코드 실행 도구 권한으로 확장하지 않는다.

Claude Pro에는 두 정확한 모델의 **플랜 연결 미확인** 카드를 두며 API 평가를 붙여 구독 경로의 성능을 보증하지 않는다. Free의 정확한 모델·버전은 미확인으로 유지한다. Gemini 무료는 자동 라우팅·정확한 모델·버전 선택 가능 여부 미확인으로 표시한다. 미확인을 선택 불가능으로 단정하지 않는다.

## 실제 추천 판단

1. 예산 → 필수 기능 → 이용 경로로 개별 후보를 판단한다. 확인된 미지원·무료만 조건의 유료 경로는 제외한다. 기능 제한·플랜/모델 연결·한국 결제 금액의 미확인은 확인 후 선택으로 둔다. 성능 자료 부족만으로 조건 충족 후보를 보류하지 않는다.
2. 정확한 모델 ID·평가 당시 버전·플랜 연결·선택 가능한 모드·날짜 있는 출처가 맞는 후보에만 작업 관련 원점수를 붙인다. 자동 라우팅이나 불확실한 구독 연결에는 붙이지 않는다. 평가 설정과 이용 medium이 다르면 핵심 문구에서 그 차이를 알린다.
3. 비용·사용량·속도·설정 부담은 성능 점수와 분리한다. API의 유료 허용은 토큰 과금 수용을 의미하며 구체적 총액을 보증하지 않는다. 원화 상한이 지정된 경우 사용량·세금이 불명확한 API 비용을 예산 이내로 확정하지 않는다. 이번 화면은 기존 예산 범주를 유지한다.

현재 앱은 원점수의 min/max 정규화·서로 다른 평가 백분율 평균·60/25/15 종합 100점을 사용하지 않는다. 기존 가중치 계산은 합성 회귀 계약에서만 남긴다. 실제 화면의 `score`와 benchmark 합계는 null이고 이름순·조건 충족 여부로 표시한다. 과거 Arena는 후보의 선정·순서·동점에 영향을 주지 않는다.

작업 관련성은 보수적으로 적용했다.

- 코딩: Terminal-Bench / FrontierCode만 연결한다. API Terra·Sonnet·Opus와 Plus Work Terra에 근거가 연결된다. 이 중 Work의 비용/도구 확인 상태는 별도다. Sol·Astra는 이번에 확보한 직접 코딩 원점수가 없어 코딩에서는 조건 기반 후보다.
- 업무 실행/워크플로 자동화 분석: AutomationBench를 Astra·Sonnet·Opus의 확인된 API 경로와 Work Astra에 연결한다. 일반 문장 품질·한국어·설문 성공률로 해석하지 않는다. 수행할 작업을 자료 분석으로 선택하고 해당 요청어를 입력한 경우에 해당한다.
- 과학 연구·시뮬레이션 분석: Astra의 Science 결과만 제한적으로 참고한다. 설문 통계 요청에는 붙이지 않는다.
- 사실 확인 분석: OpenAI 내부 사실성 자료를 보조 근거로만 제공한다. 서로 다른 비공개 표본을 같은 평가로 합치지 않는다.
- 글쓰기·설문 통계: 이번 직접 성능 근거 없음. 공식 기능·비용에 따른 조건 기반 후보를 유지한다. 무료만·직접 텍스트 입력은 기존 3개 서비스 후보를 유지한다.

## 비교 가능성

`compareEvaluationResults`는 평가 이름·버전·하위집합·단위·점수 방향·effort·도구·하네스·환경·시도 횟수·fallback·평가 주체를 확인한다. 필수 조건이 미확인 또는 다르면 원점수는 표시하지만 차이·순위는 확정하지 않는다. 같은 ID의 다른 모델 릴리스도 동일 결과로 다루지 않는다. 발표일만 다른 경우에는 차단하지 않는다.

이번 원점수들의 공개 하네스·시도 횟수 등에는 공백이 있어 **확정적인 쌍별 성능 우열은 제공하지 않는다**. 이는 자료 확보가 0건이라는 뜻이 아니다. 각 원점수는 실제 확보했고, 작업 관련 참고와 조건 기반 후보를 분리했다. 한 후보의 공백 때문에 다른 후보의 원점수까지 제거하지 않는다. 점수 null을 0점으로 바꾸지 않는다.

## 접근 실패·이용 조건·미확인

- Sonnet 5.5 시스템 카드 URL은 한 번 열람 시 약 13 MB 응답의 크기 제한 오류가 발생했다. 반복 접근·우회하지 않았다. 발표 원문의 70.6%는 수록하되 연결되지 않은 effort·하네스·시도 횟수는 추정하지 않았다.
- 소수 사실 수치를 출처와 함께 요약했다. 원문·도표·전체 리더보드·문제/출력 데이터는 복제하지 않았다. 각 출처의 별도 데이터 재배포 허가·오픈 라이선스는 미확인이며 허가가 있다고 주장하지 않는다.
- 기존 ChatGPT Free/Plus·Claude Free/Pro·Gemini 무료/Pro의 미확인/제한적 기능과 한국 결제·세금 조건을 보존했다. 이번 API 모델 발표만으로 구독 권한을 갱신하지 않는다.
- 실제 외부 계정 로그인·모델 선택·업로드·성능 실험·결제는 수행하지 않았다. 프롬프트는 확인한 경로와 입력/도구 조건에 맞춘 안내이며 모델별 최적화 검증 결과가 아니다.

## 갱신 방법

1. 공식 모델 목록·발표·도움말 원문에서 ID·릴리스·추론·지원 기능·경로를 다시 확인한다. 계열명·API 제공·일반 Chat/Work·구독 권한을 각각 조사한다.
2. 새 릴리스는 새 평가 레코드를 추가한다. 평가 릴리스 레지스트리 `evaluatedReleases`는 현재 모델 카탈로그에서 자동 계산하지 않는다. 과거 평가 버전을 바꿔 신규 버전에 점수를 상속하지 않는다.
3. 새 결과는 원점수와 공개된 조건만 입력하고 모르는 조건·날짜·횟수는 null로 남긴다. 발표/평가일과 실제 확인일을 구분한다. fallback·도구·하네스 변경은 다른 실행으로 관리한다.

### 원문 대조와 추천 기준 점검

- 표에 연결된 Sol·Terra·Sonnet·Opus 발표와 Zapier 원문 5개를 다시 열람했다. 13건의 점수·단위·점수 방향·모델 ID/버전·평가 이름/버전·effort·출처와 실제 데이터가 일치했다. `src/lib/modelCatalogAudit.test.ts`에 수동 대조한 13개 사실 조합을 고정했다. 미확인 effort·하네스·시도 횟수·평가일을 채우지 않았다.
- 평가 주체와 발표 주체를 분리한 현재 표시를 확인했다. Zapier 3건은 답변 문장이 아닌 업무 환경의 최종 상태 평가다. 제공사 발표의 실행 주체가 명시되지 않은 행은 계속 미확인이다.
- [Opus 발표](https://www.anthropic.com/claude-opus-5-5)의 AutomationBench 40.0%는 fallback 없이 실행한 Zapier 결과를 재인용한다. 앱의 42.47%는 [Zapier 원문](https://zapier.com/benchmarks)의 **default fallbacks, Max** 행이다. 차이를 오타로 취급하거나 서로 덮어쓰지 않았고 새 관측값도 추가하지 않았다.
- 13건의 모든 쌍을 검사했으며 조건 부족/차이가 있는 실제 결과는 확정 비교·원점수 차이를 반환하지 않는다. 발표일 차이만으로 비교를 막지 않는 기존 회귀도 유지한다. 원점수는 남기고 종합 점수는 null이다.

### 발견해 수정한 문제

1. `interpretTask`가 **묵시적 기본값**인 summary 모드에서도 이미지 이해 필수 조건을 제거했다. API 이미지 분석 요청에서 지원 미확인 후보까지 조건 충족으로 표시될 수 있었다. 사용자가 직접 텍스트 입력을 선택하거나 요청에 직접 입력 의사가 있는 경우에만 해당 조건을 제거한다. 이미지 이해가 남은 경우 분석 안내·프롬프트·단계 입력 안내도 이미지 입력 권한을 확인하도록 맞췄다. 기존의 명시적 텍스트 대체 경로는 유지한다.
2. 단계 화면이 `평가`라는 단어가 있는 모든 보류 이유를 숨겨 **정확한 평가 모델·버전·모드와 플랜 연결 미확인** 경고까지 누락했다. 성능 자료 부족 안내만 구분해 생략하고 이 연결 경고는 표시하도록 수정했다. 이미 보유한 모델의 thinking 제한 등도 단계의 중요 제한에 함께 표시한다.
3. 카드와 선택 이름이 미확인인 모델 선택을 `선택 불가`로 읽힐 수 있게 표시했다. 기존 자동 라우팅 기록은 유지하고 **선택 가능 여부 미확인**으로 문구를 바로잡았다. 불가능하다는 새 근거를 만들지 않았다.

위 세 회귀는 수정 전 실패를 확인한 뒤 수정 후 통과했다. 다른 추천 정책·가중치·평가 수치·플랜 매핑은 변경하지 않았다.
