# 근거 기반 추천 순위 구현·실행 기록

2026-10-28. 이번 지시가 기존의 ‘모든 확정 순위 금지·모델명 중립 정렬’ 정책을 대체한다. commit·push·배포는 수행하지 않았다.

## 실제 결과

아래는 `compareCandidates`를 실제 실행한 결과다. 전체 모델의 절대 순위가 아니라 확보한 비교 집합·평가 기준의 순위다. 평가 대상 설정과 현재 웹 채팅 이용권한은 별개다.

### 코딩

입력: `Python 코드 오류를 수정하고 테스트를 작성해줘`

| 순위 | 모델 | 평가 대상 설정 | 근거·원점수 | 이 순서의 이유 |
|---|---|---|---|---|
| 1 | Qwen3 235B A22B Instruct 2507 | non-thinking | LiveCodeBench v6, 51.8 | 선택한 동일 표·동일 기간의 최고 원점수 |
| 2 | Kimi K2 Instruct | non-thinking | 같은 평가, 48.9 | 51.8보다 낮고 45.2보다 높음 |
| 3 | DeepSeek V3 0324 | 추론 설정 미공개 | 같은 평가, 45.2 | 선택 비교 집합의 세 번째 원점수 |

[Qwen 공식 표](https://huggingface.co/Qwen/Qwen3-235B-A22B-Instruct-2507)의 **2025-02~05** 행만 사용했다. 기존 Moonshot의 Kimi 53.7은 **2024-08~2025-05**여서 이번 집합에 넣지 않았다. 점수 단위는 원문 표 점수이며 미확인 metric을 임의로 %·정답률로 바꾸지 않았다.

111건 전체를 검토해 코딩 관련 37건을 분리하고, 그중 같은 표의 검토된 3개 열로 순위를 계산했다. Terminal-Bench의 버전·agent·effort가 다른 결과나 HumanEval/Pass@5는 합산하지 않았다. 코드 생성은 관련 근거지만 실제 저장소 버그 수정·테스트 성공으로 확장하는 판단은 **간접 추론**이다. 이 제공사 표 순위는 독립 재현 또는 완전한 동일 실행 조건 검증을 뜻하지 않는다. 세 모델 모두 현재 웹의 정확 버전 연결은 미확인으로 따로 표시된다.

### 설문 분석

입력: `설문 통계값으로 집단 평균 차이를 분석해줘` / 요약 통계 직접 입력

**성능 순위 없음.** 실제 표시 순서는 다음과 같은 기능 기반 검토 순서다.

| 표시 역할 | 후보 | 선택 이유 | 표시하는 간접 참고값 |
|---|---|---|---|
| 우선 검토 후보 | Qwen3 235B A22B Instruct 2507 | 문서 이해·수학·논리 기능으로 변수·통계 설명을 먼저 정리 | AIME 2025, 70.3 |
| 대안 검토 후보 | Kimi K2 Thinking | thinking·긴 문맥 처리로 분석 가정과 해석 한계 검토 | HLE text-only, 23.9 |
| 대안 검토 후보 | Qwen3 30B A3B Instruct 2507 | 다른 생성 모델로 같은 요약 통계 설명 교차 검토 | AIME 2025, 61.3 |

111건 중 수학·추론·지식·사실성 관련 32건을 검토했다. 위 원점수는 순서를 계산하는 데 쓰지 않는다. **코딩 점수는 전혀 사용하지 않는다.** 문서 이해·일반 추론이 도움이 될 것이라는 판단은 추론으로 표시한다. 텍스트 생성 기능이 통계 계산의 정확도를 입증하지 않는다.

[StatQA 원저자 자료](https://statqa.github.io/)는 통계 방법 선택과 적용 가능성을 평가한다. 현재 등록 모델의 정확한 릴리스·설정에 연결할 직접 비교 결과는 확보하지 못했다. 이 부족 근거를 목록 상단에서 한 번 설명하며 후보마다 1·2·3위를 붙이지 않는다. 파일 입력일 때는 업로드·표 분석 도구의 웹 권한 미확인도 별도 표시한다.

### 일반 글쓰기

입력: `동아리 모집 글을 한국어 500자로 작성해줘`

**성능 순위 없음.** 실제 검토 순서:

- 우선 검토: **Qwen3 235B A22B Instruct 2507** — 지시 이행·개방형 텍스트 생성으로 독자·분량·어조를 반영한 초안 준비.
- 대안 검토: **Qwen3 30B A3B Instruct 2507** — 같은 지시를 다른 생성 모델에서 검토.
- 대안 검토: **Kimi K2 Thinking** — 긴 문맥과 장문 생성으로 긴 초안·논리 전개 검토.

표시 참고값은 각각 Creative Writing v3 87.5 / 86.0, Longform Writing 73.8이다. 서로 다른 장르·척도를 합산하거나 이 값으로 순서를 계산하지 않는다. 긴 보고서·장문 요청에서는 기능에 맞춰 Kimi Thinking을 먼저 검토하도록 제안한다.

글쓰기 관측 7건을 검토했고, [WritingBench 원저자 저장소](https://github.com/X-PLUG/WritingBench)의 문항·judge 변경 이력도 확인했다. 기존 제공사 표의 버전·judge 연결과 한국어·모집 글 장르의 직접 비교가 부족해 성능 순위를 만들지 않았다.

추가 실행: `한국어 창작 단편 소설을 써줘`는 창작과 관련된 **Creative Writing v3 공식 표 내 순위**를 표시한다. Kimi K2 Instruct **88.1 →** Qwen3 235B Instruct 2507 **87.5 →** DeepSeek V3 0324 **81.6**이다. 평가 언어·judge가 미확인이므로 한국어 소설 품질의 검증된 순위로 확장하는 판단은 추론이라는 제한을 각 카드에 표시한다.

## 데이터·화면·보존

- 기존 25개 모델·107건의 원점수는 보존했다. 같은 Qwen 표의 Kimi/DeepSeek 코딩 열 2건과 창작 열 2건을 새 ID로 보완해 **111건**이다. 원래 다른 기간·출처의 값은 덮어쓰지 않았다.
- 첫 영역에 우선 추천·대안 2개, 공동 순위, 모델·평가 대상 설정, 이유, 평가명·원점수, 관련성·중요 제한을 노출한다. 나머지 후보는 별도 펼침 영역에 둔다.
- 상세 출처·확인일·도구·agent·환경·반복·fallback·평가 한계는 펼쳐볼 수 있다. 웹 선택 설정과 평가 설정을 구분한다.
- 가격·무료 여부는 순위 계산에 쓰지 않는다. 기능 미지원에 따른 후보 제외, 웹 권한 안내, 평가 성능은 각각 별도이다.
- 기존 선택 ID와 웹 mode는 그대로 유지한다. 새 순위는 사용자의 기존 선택을 덮어쓰지 않는다. 단계별 프롬프트, 편집 초안, 재생성·이전 초안 복구 경로를 보존했다.

독립 코드 리뷰에서 발견한 지수/범위 비교, ‘다시’ 오분류, 코딩 fallback 안내 오류를 각각 재현 테스트 후 수정했다.

최종 실행: `npm.cmd test` **149/149 통과**, `npm.cmd run typecheck` 통과. `git diff --check` 통과. 선택·초안 보존, 실제 결과 렌더, 값 변경·동점·누락·비교 불가를 포함한 결과다.

검증 환경의 한계: 표준 `npm.cmd run build`는 Vite 설정을 읽는 esbuild 자식 프로세스에서 `spawn EPERM`으로 중단됐다. 직접 esbuild CLI로 로컬 확인용 번들은 생성했으나 이를 표준 Vite 빌드 성공으로 보고하지 않는다. 브라우저 접근 호스트가 제공되지 않았고, native Chrome 접근도 자동 승인 검토에서 거부되어 라이브 브라우저 검증은 수행하지 못했다. 실제 추천 함수·React SSR 렌더를 검증했다.

재현 명령: `npm.cmd test`, `npm.cmd run typecheck`, `npm.cmd run build`. 실제 추천 실행 JSON은 로컬 `.qa/evidence-ranking-results.json`에 기록한다.
