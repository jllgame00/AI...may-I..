# 요청문과 추천 카드 수정 계획

사용자의 2026-10-28 수정 지시를 명세로 삼아 현재 작업 폴더에서 직접 실행한다. 기존 미커밋 변경·데이터·출처·사용자 초안·Pages 설정을 유지하고 commit/push/배포를 하지 않는다.

- [x] 원문 회귀 사례와 데이터·Pages 해시, 수정 전 네 단계 본문을 기록한다.
- [x] 요청 분석→분량 추출→단계 생성 경로의 실패 테스트를 추가하고 실제 실패를 확인한다. 원문을 삭제·재조합하는 대신 원문과 별도의 자료·질문·설명·산출물 구조를 사용한다. 누락·미정값, 질문 순서, 사용자 조건 수정도 확인한다.
- [x] 카드 렌더링 실패 테스트를 추가한다. 최대 두 근거와 핵심 제한 하나, 선택 버튼을 기본으로 표시한다. 필수 기능·연결 미확인 후보를 별도로 표시하고 성능 근거 부족은 공통 안내한다. 중립 정렬과 배열 순서 변경을 확인한다.
- [x] 출처 링크에 문서명/내용을 붙이고 계정에서 무엇을 확인할지 행동 문장으로 안내한다. 전체 근거는 접힌 상세에 보존한다.
- [x] 전체 테스트 136개·타입 검사 통과, 실제 생성 네 단계 전후 직접 읽기·편집 복구·보호 파일 17개 해시 확인. 빌드는 환경의 spawn EPERM으로 실패. 실제 브라우저 캡처는 Chrome 접근 거부·컴퓨터 사용 승인 제한으로 미검증임을 보고서에 명시했다.
