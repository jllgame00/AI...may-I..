## 실행 기록

- 시작 상태: 25개 모델·111개 관측, 타입 오류 4건, 테스트 150 통과·5 실패. 미완성 변경을 보존·통합했다.
- 요청·추천·화면·세션·복사 연결 완료. 사용하지 않는 화면·고정 기능 후보 목록은 archive/2026-10-core-rebuild에 보존했다.
- 공식 두 카드 실수집: 기존 10+6개 관측 재확인. 공식 API에서 3개 식별 정보 추가, 현재 28개 모델·111개 관측. AA는 격리 비활성화.
- 독립 코드 검토: 설문 추가 조건 누락, 명시적 기능 해제 무시, 미정 분량 복원, 불완전 스냅샷 복구 우선의 중요 결함 네 건을 재현 후 수정. 경미한 검증 명령·변경 감지 순서·불필요한 문자열 처리도 정리했다.
- 추가 회귀: 관련 없는 코딩 집합이 대표로 승격되지 않음, 앞 단계 편집 시 뒤 단계 검토 상태 무효화. 초안 본문은 보존한다.
- 최종 자동 검증: 테스트 165/165, 타입·스냅샷·스크립트 문법·diff 검사 통과. 실제 외부 수집은 성공했으며 동일 응답 재수집에서 changedAt 유지 확인.
- 환경 제한: Vite 빌드 spawn EPERM. 브라우저 호스트 불가와 Chrome 제어 승인 거부. 실제 PC/320px/키보드/시스템 클립보드/화면 캡처는 미실행. 시도·미검증·수동 명령은 docs/core-implementation.md에 기록했다.
- commit/push/배포/워크플로 실행 없음. 설계 승인·커밋 단계는 사용자의 즉시 구현·커밋 금지 지시를 우선했다. 현재 작업 트리에서 작업했고 강제 초기화나 사용자 변경 폐기를 하지 않았다.
