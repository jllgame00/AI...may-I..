# 실제 생성된 단계별 프롬프트

현재 `buildGuideBundle`이 생성한 본문 전문입니다. 원문은 별도 맥락으로 그대로 보존하며 직접 수정한 조건이 우선합니다. 원문의 최종 분량을 분석·해석 단계의 출력 분량으로 강제하지 않습니다. 편집 후 복사하면 화면에서 편집한 내용이 복사됩니다. 실제 설문 자료나 통계 결과를 제공한 것이 아니므로 이 문서는 분석 완료 보고서가 아닙니다.

## 대표 설문 사례
