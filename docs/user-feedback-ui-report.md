# 사용자 피드백 UI/UX 개선 결과

2026-10-30, 기준 커밋 `aeba7cd`. 시작 Git 상태는 깨끗했다. 기존 커밋·아카이브·실제 사용자 원본을 보존했으며 commit·push·배포는 하지 않았다.

## 네 가지 피드백 반영

1. **예시 의미:** 예시 버튼 위에 ‘예시로 시작하기’, ‘선택하면 입력창에 예시 요청이 채워져요.’를 추가했다. 기존 세 가지 예시 내용과 `type="button"` 클릭 동작을 유지했다. 입력창만 채우며 자동 해석·제출·추천을 실행하지 않는다.
2. **예산 간소화:** 무료만·무료 선호·유료 가능의 네이티브 라디오 카드와 ‘아직 정하지 않았어요’ 동작으로 바꿨다. 미정이면 세 라디오 모두 선택되지 않는다. 숫자·통화·국가 입력은 기본 화면에서 제거하고, 원문 금액은 읽기 전용으로 표시한다. 원문에 금액이 없으면 만들지 않는다.
3. **작업 선택:** 여섯 작업을 PC 3열·모바일 2열 카드로 표시한다. 자동 해석값이 선택되며 다중 선택과 해제가 가능하다. 선택 카드는 보라색 테두리·배경과 네이티브 체크 표시를 사용한다. 라벨 전체 클릭 영역은 최소 높이 64px이며 키보드 포커스와 선택 의미를 유지한다. 수동 작업 선택은 예산·조건·원문 변경에 유지된다. 긴 기능 목록은 기존 접기 안에 두고 기본 요약은 최대 3개 기능만 표시한다.
4. **서비스명 강조:** 추천 카드 제목은 Claude·ChatGPT·Gemini 등의 서비스명, 보조 문구는 ‘Anthropic 제공’ 등으로 표시한다. 단계 화면도 서비스명을 크게 표시하고 선택 목록은 서비스명부터 읽힌다. Provider ID, 회사 단위 중복 제거, Google의 Gemini·NotebookLM 처리와 기존 선택 경로는 유지한다. 모델·버전·벤치마크·상세 요금표는 추가하지 않았다.

## 필요한 추천·분류 로직 변경

- `Budget`에 선택적 `preferFree`를 추가해 무료 선호와 미정을 구분했다. `freeOnly`의 기존 의미와 숫자 예산·통화·국가 필드는 유지한다.
- 요청의 예산은 `Partial<Budget>` override를 지원한다. 해석 시 원문 조건 위에 사용자 override를 적용하며, 새 UI는 선호 두 필드만 저장한다. 따라서 ‘월 2만원’에서 선호를 바꿔도 상한이 남고, 원문을 ‘월 1만원’으로 수정하면 새 금액을 다시 해석한다. 기존 전체 예산 override도 유지한다.
- 무료만은 기존 유료 필수 경로 제외 규칙을 사용한다. 무료 선호에서만 **조건이 같은 경로 중 공식 무료 근거가 있는 경로**를 먼저 고려한다. 유료를 무조건 제외하지 않으며, 미확인·제한된 무료 기능이 확인된 유료 기능을 앞설 수 없다. 같은 조건에서는 기존 회사명 순서를 유지한다. 새 점수나 성능 순위는 없다.
- 무료 근거 판정은 해당 서비스·플랜에 적용되는 검토된 가격 근거와 0원·무료 경로를 함께 확인한다. 국가·통화·세금이 불충분한 월 예산은 기존대로 unknown/조건부다. 한국 가격이나 결제 조건을 가정하지 않았다.
- `PPT` 약어를 발표자료 생성 요청으로 인식한다. 개요·목차·내용 기획은 텍스트 작업과 구분한다. 절별로 판단해 개요와 실제 파일을 함께 요구하면 둘 다 유지하고, 참고용 개요는 새 산출물로 만들지 않는다. 사용자 피드백 C를 점검하면서 확인한 분류 누락과 혼동을 수정한 범위다.
- 이미지·슬라이드·영상 생성 기능이 미확인인 경로의 사용 안내는 지원 여부를 먼저 확인하도록 바꿨다. 해당 기능이 가능한 것처럼 실행 방법을 단정하지 않는다.

공식 카탈로그·seed·근거·아카이브·실제 SURVEY 응답은 바이트가 같다. 허용한 수정 파일 외 기존 추적 파일 306개를 기준 해시와 대조했다. 새 회사·서비스·플랜·모델·근거 데이터나 라이브러리는 추가하지 않았다.

## 피드백 사례 A/B/C

아래는 **앱의 실제 분석·추천·프롬프트 생성 코드 실행 결과**다. 외부 AI가 결과물을 생성한 실험 결과가 아니다. 예산과 국가는 입력되지 않았으므로 미정이다.

## 추천·프롬프트 보존

기존 8개 대표 요청(설문, XLSX, PDF, 대본, 코드, 이미지, 무료 이미지, 복합 작업)에 대해 전후 필수 기능·모든 경로의 기능/예산 판정·대표 회사/플랜·후보 표시 순서·단계별 회사 선택지·프롬프트 전문이 동일했다. 모든 가능한 자연어 입력이 같다는 주장은 아니다.

의도한 변화는 새 무료 선호에서 근거 있는 무료 경로를 먼저 고려하는 것과, 누락된 PPT 파일 요청 및 PPT 기획/참고 입력을 구분하는 것이다. 이 외 비교한 기존 요청의 추천 변화는 발견하지 않았다. 편집 초안 보존, 회사 변경, 복사·재생성·복구, 공식 근거와 모델 정보 비노출의 기존 테스트를 유지했다.

## 남은 확인

일반 Windows PowerShell에서 아래 명령을 실행해 프로덕션 빌드·브라우저 E2E·PC/모바일 스크린샷을 확인해야 한다. 새 E2E에는 가로 넘침·최소 클릭 영역·키보드 조작·선택 보존 검사와 화면 캡처가 포함되어 있다.

```powershell
npm run build
npx playwright test --list
npx playwright test
```

원문 예산은 입력창에서 수정하며, 기존 전체 예산 override를 외부에서 제공한 세션은 그 명시값을 우선한다. 복잡한 부정·생략·혼합 요청에는 규칙 기반 분류의 한계가 있어 사용자가 작업·기능을 검토해야 한다. 실제 서비스 권한·지역·사용량 및 외부 AI 결과 품질은 이 UI 변경으로 보장하지 않는다.
