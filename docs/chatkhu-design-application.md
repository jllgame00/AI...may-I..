# ChatKHU 조사·설계 반영 기록

## 근거와 실행 방침

기존 AI...may I..? MVP에 ChatKHU의 조사·설계를 반영하여 Codex로 개발한다. ChatKHU가 기존 MVP 전체를 제작했다는 의미가 아니다.

2026-10-28 작업 시작 시 `AGENTS.md`는 프로젝트 파일 검색에서 발견되지 않았다. 기존 React 19 / Vite 7 / TypeScript / Tailwind 4를 유지한다. 원래 작업 트리의 미추적 DOCX 두 개는 사용자 자료로 보존한다. 사용자 지정 현재 프로젝트에서 작업하고 commit/push/배포/의존성 추가는 하지 않는다. 기존 Pages base `/AI...may-I../`와 워크플로를 유지한다.

읽은 문서: `AI_may_I_정보구조_UIUX_Codex설계명세.docx`, `AI_may_I_개발자료_조사비교_20261028.docx` (ZIP 내 document.xml의 본문·표 텍스트 추출). 요청된 `AI_may_I_확대카탈로그_1차조사_20261028.docx`는 없으며 다른 조사 문서를 그 파일이라고 간주하지 않는다. 사용자 명세의 전체 13개 / 첫 묶음 7개 모두 부분 조사 / 필수 전체 확인 완료 0개를 범위 메타데이터로 반영한다. 첫 묶음 7개 구성과 나머지 4개 서비스의 상세 근거는 확보하지 못했으므로 임의로 채우지 않는다.

## 구현 계획과 진행 기록

1. 데이터와 조건 판정: 13개 서비스 레지스트리, 조사 상태/작업 적합성 분리, 플랜별 근거와 상충 보존. 기존 조건 추출·추천 엔진을 확장하고 실제 평가 요건은 보존한다.
2. 입력·탐색·비교: 누락 질문 최대 3개, 선택적 세부 수정, hash 화면 이동, 서비스 검색·상세·서비스+플랜 최대 3개 비교. 미확인 서비스에 가상 플랜을 만들지 않는다.
3. 프롬프트·단계: 상위 상태의 편집 초안·이전 초안, 명시적 재생성·복구, 실제 복사 결과, 별도 공식 링크, 사용 안내·후속 질문·자기 점검. 단계별 선택과 후속 재확인을 연결한다.
4. 회귀 검증: 조건·상태·비교·초안·단계·과거 평가 영향 테스트 → 타입 검사 → 빌드 → 가능한 실행·브라우저 확인. T01~T16 결과를 아래에 기재한다.

기준 실행: `npm`은 PowerShell의 npm.ps1 실행 정책으로 실패하여 공식 Windows 실행 파일 `npm.cmd`를 사용한다. `npm.cmd test`는 논리 테스트 49개 통과, 렌더 테스트는 설치되지 않은 typescript로 시작 실패했다. lockfile 기반 `npm.cmd ci`로 기존 의존성을 준비한다.

## 자료 대조와 남은 미확인

- 제공 조사 문서의 D 출처 목록에는 **각 출처별** 2026-10-28 열람 또는 접근 시도 기록이 있다. `researchOverlay.ts`는 그 기록에 해당하는 필드만 추가한다. 이 작업에서 공식 사이트를 새로 열람/실사용했다고 주장하지 않는다. 문서 작성일을 임의로 다른 기존 출처의 확인일에 덮어쓰지 않았다.
- ChatGPT PDF: 10/21 기존 일반 파일 안내의 지원 주장과 10/28 PDF 전용 FAQ 미열람 기록은 확인 범위가 다르다. 두 근거와 날짜를 보존하고 플랜별 PDF 내용 분석은 보수적으로 미확인 유지. 일반 업로드와 PDF를 분리한다.
- Gemini: 미가입 상태를 가상 ‘Free 상품명’으로 확정하지 않는다. 보고서의 한국 Pro 월 29,000원·PDF 문서상 지원을 반영하되 세금·실제 총액·스캔·암호·표/페이지 한도는 미확인. 무료의 제한적 지원은 구체 작업이 제한 내에 든다는 근거가 없으므로 조건부로 유지한다.
- Claude: $20 월 결제, $200 연 선결제, 월 $17 공식 표시를 별도 필드로 보존. ISO 통화코드·적용 국가·한국 금액은 null/미확인. 파일 생성은 업로드 근거로 쓰지 않는다.
- 부가 기능은 일반 파일 업로드/PDF 분석/이미지 입력/시트 분석/코드 실행을 플랜별로 나눈다. 코드 작성 요청과 코드 실행 도구 요구도 구분한다. 검색·코드 실행 안내는 해당 플랜·경로의 문서상 지원과 한계를 따른다.
- 새 10개 후보의 상세 근거·정확한 플랜은 미확보. 공식 홈페이지 안내 링크는 카탈로그 진입용이며 접근·기능 실시간 확인 완료가 아니다. Mistral Vibe/Le Chat는 사용자 제공 명칭으로 등록하고 명칭 전환의 공식 확인을 보류했다.
- 정확한 현재 모델·버전·추론 설정·평가 엔드포인트와 플랜의 연결은 미확인. 기존 unknown 연결을 유지하고 제공 문서의 모델명 예시를 운영 매핑으로 채우지 않았다.

## 남은 제한과 재실행 방법

1. 읽을 수 없었던 확대 카탈로그 원본의 7개 상세 조사 내역을 받으면 **필드별**로 추가 대조해야 한다. 현재 10개 후보의 상세 플랜/기능은 미확인 상태다. 이것이 13개 전체의 조사 완료를 의미하지 않는다.
2. 로컬 의존성 설치가 권한 오류로 끝나 타입 검사·렌더 테스트·빌드·실제 브라우저 완주를 검증하지 못했다. 코드 리뷰로 일부 문제는 고쳤으나 타입·런타임 문제가 더 없다고 보증하지 않는다. 정상 쓰기 권한이 있는 터미널에서 아래 명령으로 먼저 재검증해야 한다. 실행 정책 변경이나 캐시 우회는 제안하지 않는다.
3. 현재 세션은 현재 탭의 메모리 수명이다. 새로고침 지속 저장·계정 간 동기화·다중 이력 초안 저장은 범위 밖이다. 뒤로 가기 포커스는 ID 또는 동일 화면 조작 요소 순서로 복원하므로 실제 브라우저에서 검증해야 한다.
4. 안내의 ‘지원’은 문서상 기능이며 실제 파일 처리·정확성·사용량·한국 결제 총액 보장이 아니다. 외부 서비스 결과의 자기 점검은 인증이 아니다.
