# SURVEY-01 원문 보존 상태

사용자의 제품 방향 정리에 따라 **정식 채점·신규 루브릭·회사 성능 벤치마크 구축은 중단했습니다.** 이 폴더의 8개 응답은 프롬프트 생성기의 결과물 완성도를 검토하기 위한 테스트 사례로만 보존합니다. 저장 위치의 `results`라는 이름이 정식 평가 등록이나 성능 검증을 뜻하지 않습니다.

- `raw/`: 사용자가 제공한 실제 서비스 응답 8건. 오탈자·Markdown·분기/설정 오류를 포함해 수정하지 않았습니다.
- `internal/received-message.md`: 파일명별 수신 코드 블록 보존본.
- `internal/raw-hashes.json`: 파일명·서비스·회차·UTF-8 바이트 수·SHA-256. 원문 8개 모두 비어 있지 않고 내용 해시는 서로 다릅니다.

이번 작업에서 만든 미승인 루브릭 초안과 미완성 평가 테스트는 제거했습니다. 공식 자동/수동 점수·익명 평가 제출·추천 반입·회사 순위는 생성하지 않았고, 기존 `survey-v1` 및 `evaluations/results/registry.json`은 변경하지 않았습니다.

원문에 적힌 설문 예상 소요 시간은 실제 서비스 실행 소요 시간이 아닙니다. 실제 실행 날짜·플랜·모드·시간은 확인되지 않았으며 추정하지 않습니다.

추천은 기존과 같이 사용자 작업·필요 기능·공식적으로 확인된 이용 조건에 근거합니다. 실측 성능 평가가 없다는 이유로 추천을 차단하지 않습니다. 이후 검토의 우선순위는 작업 분류, 기능 매칭, 추천 이유·제한사항의 명확성, 프롬프트 결과물 완성도입니다. 이 기록은 제품 코드나 기존 미커밋 프롬프트 개선 작업을 변경하지 않습니다.

commit·push·배포는 하지 않았습니다.
