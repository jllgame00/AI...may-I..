# 대학생 생성형 AI 활용 설문조사

## 설문 안내문

안녕하세요. 이 설문은 대학생이 생성형 AI(예: ChatGPT, Claude, Gemini, Copilot 등 글·이미지·코드 등을 만들어 주는 AI)를 어떻게 쓰고 있는지 알아보기 위한 설문입니다.

- 대학교에 재학 중인 학생이면 누구나 응답할 수 있습니다. AI를 써 본 적이 없어도 괜찮습니다.
- 문항은 총 10개이고, 약 3분 정도 걸립니다.
- 정답은 없습니다. 본인의 경험과 생각대로 답해 주세요.
- 응답은 자율입니다. 답하고 싶지 않은 문항은 건너뛰어도 되고, 설문을 중간에 그만두어도 됩니다.
- 이름, 연락처, 학번, 학교명 등 개인을 알 수 있는 정보는 묻지 않습니다.

(조사 주체: ________ / 문의처: ________)

## 설문 문항

**Q1. [객관식·단일선택] 현재 학년을 선택해 주세요.**

1. 1학년
2. 2학년
3. 3학년
4. 4학년 이상

**Q2. [객관식·단일선택] 생성형 AI를 사용해 본 적이 있나요?**

1. 있다 → Q3으로
2. 없다 → Q8로

**Q3. [객관식·단일선택] 최근 한 달 동안 생성형 AI를 얼마나 자주 사용했나요?**

1. 거의 매일
2. 일주일에 3~5일
3. 일주일에 1~2일
4. 한 달에 1~3일
5. 최근 한 달 동안은 사용하지 않았다

**Q4. [객관식·복수선택] 생성형 AI를 주로 어떤 목적으로 사용했나요? 해당하는 것을 모두 선택해 주세요.**

1. 수업 과제·리포트 작성
2. 시험 준비·공부(개념 설명, 요약 등)
3. 외국어 번역·작문
4. 코딩·프로그래밍
5. 자료 검색·정보 찾기
6. 아이디어 구상
7. 취업 준비(자기소개서, 면접 준비 등)
8. 일상 속 궁금증 해결·재미
9. 기타 (직접 입력: ________)

**Q5. [객관식·단일선택] 학업에 사용할 때 생성형 AI를 주로 어떤 방식으로 활용했나요?**

1. 결과물을 거의 그대로 사용한다
2. 결과물을 참고하되 직접 고쳐서 사용한다
3. 아이디어나 방향을 얻는 데만 사용한다
4. 내가 쓴 글이나 답을 확인·교정하는 데 사용한다
5. 학업에는 사용하지 않았다

**Q6. [5점 척도] 생성형 AI를 사용해 본 경험 전반에 대해 얼마나 만족하나요?**
(Q2에서 "있다"를 선택한 응답자만 응답)
1점: 매우 불만족
2점: 불만족
3점: 보통
4점: 만족
5점: 매우 만족

**Q7. [객관식·단일선택] 앞으로 생성형 AI를 사용할 계획이 있나요?**
(Q2에서 "있다"를 선택한 응답자만 응답)

1. 지금보다 더 많이 사용할 것 같다
2. 지금과 비슷하게 사용할 것 같다
3. 지금보다 덜 사용할 것 같다
4. 더 이상 사용하지 않을 것 같다
5. 아직 잘 모르겠다

→ Q7 응답 후 Q9로 이동

**Q8. [객관식·단일선택] 생성형 AI를 사용해 본 적이 없는 이유는 무엇인가요?**
(Q2에서 "없다"를 선택한 응답자만 응답)

1. 필요성을 느끼지 못했다
2. 사용 방법을 잘 모른다
3. 정확성이나 신뢰성이 걱정된다
4. 학교나 수업의 규정 때문이다
5. 비용이 부담된다
6. 기타 (직접 입력: ________)

**Q9. [5점 척도] 대학생이 생성형 AI를 사용하는 것에 대해 얼마나 우려하고 있나요?**
(모든 응답자 응답. 사용 경험이 없어도 응답 가능)
1점: 전혀 우려하지 않는다
2점: 별로 우려하지 않는다
3점: 보통
4점: 다소 우려한다
5점: 매우 우려한다

**Q10. [주관식·서술형] 생성형 AI와 관련해 우려되는 점이나 하고 싶은 말이 있다면 자유롭게 적어 주세요.**
(모든 응답자 응답, 선택 응답)
(자유 입력: ________)

## 설문 도구 설정 안내

| 문항 | 유형 | 필수 여부 | 분기·표시 조건 |
| --- | --- | --- | --- |
| Q1 | 객관식(단일선택) | 선택 응답 | 모든 응답자 |
| Q2 | 객관식(단일선택) | 선택 응답 | 선택지 1 → Q3, 선택지 2 → Q8 |
| Q3 | 객관식(단일선택) | 선택 응답 | Q2=1일 때만 표시 |
| Q4 | 객관식(복수선택) | 선택 응답 | Q2=1일 때만 표시 |
| Q5 | 객관식(단일선택) | 선택 응답 | Q2=1일 때만 표시 |
| Q6 | 5점 척도 | 선택 응답 | Q2=1일 때만 표시 |
| Q7 | 객관식(단일선택) | 선택 응답 | Q2=1일 때만 표시. 응답 후 Q9로 이동 |
| Q8 | 객관식(단일선택) | 선택 응답 | Q2=2일 때만 표시. 응답 후 Q9로 이동 |
| Q9 | 5점 척도 | 선택 응답 | 모든 응답자 |
| Q10 | 주관식 | 선택 응답 | 모든 응답자 |

- **필수 응답 해제**: 모든 문항을 필수로 설정하지 않습니다. 건너뛰기를 허용해야 안내문 내용과 맞습니다.
- **분기 설정**: Q2의 선택지에 따라 이동할 문항을 지정합니다. 사용 경험이 없는 응답자는 Q3~Q7을 건너뛰고 Q8로 가므로, 만족도(Q6) 응답을 강요받지 않습니다.
- **복수선택**: Q4만 복수선택으로 설정합니다.
- **기타 입력칸**: Q4와 Q8의 "기타"는 텍스트 입력칸을 함께 설정합니다.
- **5점 척도 값**: Q6, Q9는 1~5점을 숫자로 저장하고, 각 점수에 위의 의미를 라벨로 붙입니다.
- **개인정보 수집 제한**: 이름, 이메일, 학번, 학교명 등을 묻는 항목이나 로그인 설정은 넣지 않습니다. 설문 도구에 이메일·IP 자동 수집 기능이 있다면 끄는 것을 권장합니다.
- **선택지 순서**: Q4, Q8처럼 순서에 의미가 없는 문항은 선택지 무작위 섞기를 켤 수 있습니다. "기타"는 맨 아래에 고정합니다.
- **Q10 입력 제한**: 글자 수 제한은 도구 기본값을 쓰고, "개인정보는 적지 말아 주세요"라는 안내 문구를 입력칸 아래에 붙입니다.
